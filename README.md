# Sacred-Dungeons
Sacred Dungeons conta a história de um padre que após se cansar da corrupção do mundo, parte em uma aventura para derrotar o Rei demônio, porém algo inesperado muda o rumo da história.   Um jogo por Lucas Calumbi Toscano de Brito, Omar Khayyam Formiga Aguiar e Gustavo Almeida Borba
